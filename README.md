# Zero Sugar — 30s Motion Graphic Spot

A 30-second, 16:9 (1920×1080) motion graphic concept ad. Kinetic typography, synthesized background music and a voiceover, built as a single HTML file.

## How to play
1. Open `zero_ad.html` in Chrome or Edge.
2. Click the ▶ button (or press Space) to play with sound.
3. Press **● MP4/WebM으로 저장** to record 30 seconds and download a video file.

To use your own can image, put a transparent PNG named `can.png` next to the HTML file.

## Files
- `zero_ad.html`: the full ad (music and voice built in)
- `vo*.wav`: voiceover sources (Windows SAPI voices)
- `voice.js`: the voiceover as Base64 (already embedded in the HTML)
